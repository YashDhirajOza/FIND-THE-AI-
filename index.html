📖 The 5 Detection Methodologies Explained

A deep dive into how computer scientists mathematically distinguish human thought from transformer autoregression.

01

Statistical & Stylometric Analysis

Measures mathematical variance in sentence lengths, lexical density, and predictability scores.

  • Perplexity: Calculates \(\exp(-\frac{1}{N}\sum \log P(w_i))\). Low perplexity means the text followed the most obvious path.
  • Burstiness: Measures \(\sigma / \mu\) of sentence word counts. Humans naturally write in irregular bursts; LLMs write with rhythmic monotony.
  • Entropy: Evaluates the Shannon entropy of vocabulary distribution.
Fast (CPU-only) Explainable Sensitive to Length
02

Zero-Shot Probability Curvature

Contrasts likelihood energy landscapes without requiring any labeled training datasets.

  • Binoculars: Contrasts an *Observer* model with a *Performer* model to calculate normalized cross-perplexity ratios.
  • Fast-DetectGPT: Analyzes conditional probability curvature. Perturbing AI text causes a steep drop in likelihood compared to human text.
Zero Dataset Shift High SOTA Accuracy Domain Agnostic
03

Disentangled Neural Classifiers

Deep learning models trained specifically to spot fine-grained synthetic patterns.

  • DeBERTa-v3 Large: Decouples token content embeddings from relative positional vectors. This allows the model to spot abnormal syntactic transitions.
  • RAID Benchmark: Evaluated across 10M+ documents and 11+ frontier LLMs to prevent overfitting.
95%+ Controlled Accuracy Robust to Synonyms
04

Cryptographic Source Watermarking

Embedded directly during generation by the LLM provider (e.g. SynthID-Text).

  • Token Selection Bias: A pseudo-random key partitions the vocabulary into 'green' and 'red' lists at each step, favoring green tokens imperceptibly.
  • Detection: A statistical z-score tests whether green tokens appear with higher probability than pure chance.
Zero False Positives Requires Source Support

⚔️ The Evasion Laboratory: Humanizers vs. Detectors

How modern AI humanizers attempt to bypass detectors, and how our multi-layered architecture catches them.

ATTACK VECTOR 1

The Synonym Scrambler (QuillBot Style)

Replaces common AI words with awkward, rare synonyms to artificially lower the Top-10 token count.

Bypasses: Simple GLTR and word frequency counters.
Our Defense: DeBERTa-v3 Semantic Invariance: Contextual attention vectors capture the underlying semantic flow regardless of surface-level synonym swaps.
ATTACK VECTOR 2

Burstiness Injection (StealthWriter Style)

Artificially breaks long sentences into 2-word fragments to manipulate sentence length variance.

Bypasses: Naive standard deviation length formulas.
Our Defense: Grammatical Dependency Depth: We analyze subordinate clause complexity, not just character counts or periods.
ATTACK VECTOR 3

Hybrid Co-Authoring & Partial Rewrites

A human writes the thesis and conclusion, while an AI drafts the body paragraphs.

Bypasses: Document-level single aggregate scoring.
Our Defense: Sentence-by-Sentence Forensic Heatmap: Isolates the exact paragraph transitions where synthetic generation begins.

🗺️ Production Backend Architecture

The Python / PyTorch / FastAPI architecture designed to power the full-scale engine.

core_engine.py (Python / PyTorch / Transformers) 
import torch
import numpy as np
from transformers import AutoModelForCausalLM, AutoTokenizer, AutoModelForSequenceClassification

class FindTheAIDetector:
    def __init__(self, base_model="gpt2", classifier_model="microsoft/deberta-v3-large"):
        # 1. Statistical Perplexity & Zero-shot Tokenizer
        self.tokenizer = AutoTokenizer.from_pretrained(base_model)
        self.lm_model = AutoModelForCausalLM.from_pretrained(base_model).eval()
        
    def compute_perplexity(self, text: str) -> float:
        inputs = self.tokenizer(text, return_tensors="pt")
        with torch.no_grad():
            loss = self.lm_model(**inputs, labels=inputs["input_ids"]).loss
        return float(torch.exp(loss).item())

    def compute_burstiness(self, sentences: list) -> float:
        lens = [len(s.split()) for s in sentences if len(s.strip()) > 0]
        if len(lens) <= 1: return 0.0
        return float(np.std(lens) / (np.mean(lens) + 1e-8))

    def ensemble_predict(self, text: str) -> dict:
        sentences = [s.strip() for s in text.split(".") if len(s.strip()) > 0]
        ppl = self.compute_perplexity(text)
        burst = self.compute_burstiness(sentences)
        
        # Calibrated Sigmoidal Probability Scaling
        prob_ppl = 1.0 / (1.0 + np.exp((ppl - 42.0) / 8.0))
        prob_burst = 1.0 / (1.0 + np.exp((burst - 0.45) / 0.15))
        
        ai_score = (0.55 * prob_ppl + 0.45 * prob_burst) * 100
        return {
            "ai_percentage": round(ai_score, 2),
            "perplexity": round(ppl, 2),
            "burstiness": round(burst, 2),
            "sentence_count": len(sentences)
        }
