LOCAL INFERENCE ENGINE

FastAPI & PyTorch Backend

Run the genuine 5-node PyTorch inference backend locally on your machine with full GPU acceleration.

backend/server.py (FastAPI REST Server) 
# 1. Install dependencies
pip install -r backend/requirements.txt

# 2. Run local FastAPI inference server
uvicorn backend.server:app --host 127.0.0.1 --port 8000 --reload

# 3. Analyze text via REST API
curl -X POST http://127.0.0.1:8000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Artificial intelligence is transforming the modern technological landscape..."}'
